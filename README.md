# FolderScan - フォルダ内ファイル一覧出力マクロ

指定したフォルダ以下（サブフォルダも含む）にあるすべてのファイルを調べ、ファイル名・フォルダパス・サイズ・更新日時・作成日時を一覧にまとめるExcel VBAツールです。
「大量のファイルの棚卸しをしたい」「どのフォルダに何がどれだけあるか一覧化したい」といった作業の自動化を想定しています。

## ダウンロード

**[⬇️ FolderScan.xlsm をダウンロード](https://github.com/tndnkjp/folderscan-tool/raw/main/FolderScan.xlsm)**

上のリンクをクリックするだけで、ブラウザが自動的にファイルをダウンロードします（gitの知識は不要です）。

## できること

- 1つのフォルダを選択するだけで、配下の全ファイルを一覧化
- サブフォルダの中のファイルも自動的に対象（既定）
- ファイル名・フォルダパス・サイズ（バイト）・更新日時・作成日時を一覧シートに出力
- アクセス権限がないフォルダ・ファイルは自動でスキップし、件数を通知
- ワンクリックで`一覧`シートを削除してリセット

## 使い方

1. **[`FolderScan.xlsm` をダウンロード](https://github.com/tndnkjp/folderscan-tool/raw/main/FolderScan.xlsm)して開く**
2. 開いた際に以下のいずれかが表示されることがあります（出ない場合はそのまま手順3へ）
   - 黄色いセキュリティバー → 「コンテンツの有効化」をクリック
   - 赤い「セキュリティリスク」の警告（「このファイルのソースが信頼できないため、Microsoft によりマクロの実行がブロックされました」）→ 下記FAQ「ファイルを開くとマクロがブロックされて実行できない」を参照
3. 「**一覧を出力する**」ボタンをクリック
4. フォルダ選択ダイアログで、一覧化したいフォルダを指定
5. 完了すると `一覧` シートに、対象フォルダ以下の全ファイルが表示される

結果をリセットしたい場合は、「**一覧シート削除**」ボタンを押してください。

これだけで使えます。VBAエディタを開く必要はありません。

## つまずきやすいポイント（FAQ）

### ファイルを開くとマクロがブロックされて実行できない

Excelの初期設定では、インターネット経由で取得したファイルのマクロは既定でブロックされます。症状としては主に次の2パターンがあります。

**パターン1：黄色いセキュリティバーが表示される**

「コンテンツの有効化」をクリックすれば使えます。

**パターン2：赤い「セキュリティリスク」の警告が表示され、「コンテンツの有効化」ボタンが出ない**

「このファイルのソースが信頼できないため、Microsoft によりマクロの実行がブロックされました」という表示です。これは最近のOfficeで追加された、より厳しいブロックで、Excelを開いたまま警告バーをクリックしても解除できません。**一度Excelを閉じてから**、以下の手順でブロックを解除してください。

1. ダウンロードした `FolderScan.xlsm` を右クリック → `プロパティ`
2. 「全般」タブの下部に「セキュリティ: このファイルは他のコンピューター上にあり、…」という注意書きと「許可する」チェックボックスがあるので、チェックを入れる
3. 「OK」で閉じる
4. あらためて `FolderScan.xlsm` を開く

それでも解消しない場合：`ファイル` → `オプション` → `セキュリティセンター` → `セキュリティセンターの設定` → `マクロの設定` で「警告を表示してすべてのマクロを無効にする」になっているか確認してください。

### ファイルの並び順が名前順になっていない

ファイルの並び順はWindowsが返す順序に依存し、必ずしも名前順・パス順にはなりません。Excelの「並べ替え」機能（データタブ）で、好きな列を基準に並べ替えてください。

### 対象フォルダが大きいと時間がかかる／固まったように見える

ファイル数が非常に多いフォルダ（数万件単位）を対象にすると、走査に時間がかかります。画面下部のステータスバーに進行状況が表示されるので、しばらくお待ちください。

### 環境依存文字（①②③、㈱、髙 など）を含むファイル名が文字化けする

本ツールはファイルの中身ではなく、ファイルシステムの情報（名前・サイズ・日時）をWindowsから直接取得しているため、通常はCSVの文字コードのような問題は発生しません。もし文字化けが発生する場合は、Excel側のフォント設定やWindowsの地域設定に起因する可能性があるため、別環境での再現有無をご確認ください。

## カスタマイズしたい場合

既定の設定を変えたい方向けに、VBAソースコードを `src/modFolderScan.bas` として同梱しています。

1. `FolderScan.xlsm` を開き `Alt + F11` でVBEを開く
2. 左側のプロジェクトエクスプローラーで既存の `modFolderScan` を右クリック →「解放」で削除
3. `ファイル` → `ファイルのインポート` から `src/modFolderScan.bas` を選び直す
4. 冒頭の「設定セクション」の定数を書き換えて保存

| 定数 | 内容 |
|---|---|
| `INCLUDE_SUBFOLDERS` | サブフォルダの中まで対象にするか |
| `OUTPUT_SHEET_NAME` | 一覧を書き出すシート名 |

> `src/modFolderScan.bas` はShift-JIS(CP932)で保存されています。テキストエディタで直接編集する場合、UTF-8で上書き保存すると、VBEへの再インポート時に日本語コメントが文字化けするのでご注意ください。

## 動作確認用サンプル

`sample_data/サンプルフォルダ/` に、サブフォルダを含むテスト用フォルダを同梱しています。`FolderScan.xlsm` の「一覧を出力する」ボタンでこのフォルダを指定すると、動作を確認できます。
